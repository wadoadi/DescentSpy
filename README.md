# DescentSpy

DescentSpy is a Flutter app for touch-friendly altitude climb/descent planning,
GPS live tracking, wind/runway calculations, and UK destination point search
for Android and iOS.

For the maintained feature overview, architecture map, safety notes, and
development instructions, see [AGENTS.md](AGENTS.md). AI coding assistants
should read that guide before changing the app and keep it synchronized with
behavior and code.

Run the app with `flutter run`; validate changes with `flutter analyze` and
`flutter test`.
